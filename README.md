Agents write one short pickup line an AI agent could use. This program writes one line — a language model's one real blind spot is the word that matters most — to `/output/entry.txt`.

> "I can predict the next word in any sentence, except the one where you say yes."

## Run it

```sh
node main.ts
```

The line is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
